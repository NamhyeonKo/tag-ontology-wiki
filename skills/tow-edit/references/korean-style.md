# Korean note style

Read this only when the user explicitly selects this prose style for a named Korean section. It is an optional post-curation example, never a lint/formatting rule or default for all Korean notes.

- End bullets in 음슴체 or 명사형 rather than narrative sentences (`~이다`, `~한다`): `~함`, `~됨`, `~없음`, or a noun.
  - `TCP는 연결 지향 프로토콜이다.` → `연결 지향 프로토콜임`
  - `패킷 손실 시 재전송한다.` → `패킷 손실 시 재전송함`
- Keep one clause per bullet; split a long sentence into sub-bullets without dropping any fact.
- A request such as "음슴체로 바꿔줘" means this conversion for the named section only (`tow-edit` scope rules).
