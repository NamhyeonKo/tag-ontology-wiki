# Categories

Use `category:` for registered knowledge domains, content identifiers, or project names. It is classification, not a list of concepts covered; put reusable concepts in `tags:`. Write tag examples in backticks in this manual; do not add Obsidian `tags:` frontmatter to it.

- Use lowercase letters and hyphens, with `/` for hierarchy; capitals are reserved for proper nouns.
- Categories are a list. The first item is primary and should align with the note's location; additional items are secondary classifications.
- The primary value is a project name in the projects folder, a content identifier (such as `book/<title>`) in areas, or a knowledge domain in resources.
- Register a new category only after user approval. Use the first category on the note as its primary classification. `tow find <prefix>` matches a value and its descendants.
